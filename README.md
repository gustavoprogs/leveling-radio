# Leveling Radio

Portal comunitario para Leveling Idle 2D, com rádio online, notícias, ranking e recursos sociais.

## Stack inicial

- React + Vite
- Interface responsiva com identidade visual dark fantasy em roxo e azul
- Backend, autenticação e streaming serão integrados nas próximas etapas

## Desenvolvimento

```bash
npm install
npm run dev
```

## Status

MVP em desenvolvimento. Dados demonstrativos não representam informações oficiais do jogo.
